## Derived-layout dependency protection

Campus source retains, per related role, the exact unit source identity plus physical source and compiled-shape digests used when authoring the derivative geometry. Admission checks these witnesses before replacing related physical applicability pins. Generic runtime dependency validation checks them again against the actual matching retained layout. A unit-only physical-source change or compiler-only shape change cannot acknowledge stale campus geometry merely by repinning a catalog reference. Presentation-only changes remain compatible.

This is evidence of which accepted geometry was used, not automatic verification that every future family compiler change preserves engineering nozzle equivalence. Deliberate re-authoring and review are still required.
