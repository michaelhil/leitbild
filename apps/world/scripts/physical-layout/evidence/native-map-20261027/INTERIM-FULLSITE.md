# Interim full-site Plan scaling finding

This diagnostic uses the same retained interim R4 Run as `EARLY-PLAN.md`. Source and compiler remained unchanged. It does **not** accept final orientation, routes, scoped caps, CPU residency or final-product performance. The raw paths and SHA256 receipts are in `interim-fullsite.json`.

The actual native-map test covered all five layouts, then the authored hall/annex area, with Plan/3D paused/playing windows. On `d569e94f4`, whole-site Plan achieved only 123/127 RAF intervals in four seconds, with 33.4/49.9 ms p95. The other six windows achieved 16.7–16.8 ms p95. There were zero renderer exceptions or long tasks in this unprofiled pass; all five Plan layouts were ready. A successful small-room check would have missed the whole-site regression.

The separate CPU profile attributed approximately 2.03 s of a 4.30 s diagnostic window to the Svelte Plan drawing effect (1.86 s inclusive in the painter), plus 0.93 s in `getParameter` from an empty GL pass. The renderer still captured shared state, cleared and composited its owned framebuffer even when every vector Plan entry deliberately skipped the 3D draw. The painter also rebuilt RGB strings and occurrence lookups repeatedly. The profile is an intentionally failed diagnostic run, not a clean motion sample; its path is `interim-site-plan-profile/map-site-plan-paused.cpuprofile`.

A UI-only build `7552edca4` applied the already integrated renderer/palette portions of `41d7d7264` and painter portion of `7ed3f1483`, without changing source or compiler files. It achieved 202/216 RAF intervals and 33.3/33.3 ms p95 in whole-site Plan. The other six windows remained 16.7–16.8 ms. The changes materially improve throughput but **do not meet the prior 16.8 ms target**. Further painter work and final full-source qualification are required; no geometry or captions were deliberately dropped.

The new single-map loading observer was functionally calibrated on the earlier unchanged build: first-family draw 2289.8 ms, actual first draw of both required families 2345.9 ms, and their completed fence 2368.8 ms after explicit full-site dispatch. The observer saw four repeated unit instances and one campus before placing that fence. These are calibration values from an already running local service, not a controlled speedup or cold Run-restoration claim. Vector Plan milestones separately observe actual ink plus two scheduling frames. The complete final-source run remains pending.
