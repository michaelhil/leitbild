# Private geometry-worker payload

The source worker still delivers the complete admitted scene, including every native Plan primitive, to the host. The host keeps that drawing for Plan painting and ink picking. The generic geometry worker does not consume `scene.planDrawing`: its preparation graph reads objects (including `planLines`), levels, layers, scopes and `planAnnotations`. Registration therefore omits only the separate Plan drawing from its owned transferable copy. There is no change to source admission, per-instance validation, solid/line geometry, materials, source leases or view identity.

`payload-census.json` compiles the committed R6 unit and campus sources with the native drafting compiler and records six alternating structured-clone pairs in Bun 1.4.0. Each clone transfers the same owned geometry buffers. The unit's four Plan levels contain 4,459 primitives, whose JSON representation is 2,055,666 bytes; the campus's two levels contain 1,311 primitives, whose JSON representation is 630,345 bytes. Geometry transfer remains 25,323,840 and 27,598,236 bytes respectively. JSON size is a descriptive object-graph census, not a browser transfer-byte measurement.

The Bun diagnostic takes approximately 18–22 ms versus 6–7 ms for a unit clone, and approximately 7 ms versus 3–4 ms for campus. These are local clone timings, **not** a claim to remove the site's remaining three-second cold load. Actual built-app qualification must measure worker startup, main-thread acknowledgement scheduling, preparation and drawing together on the same R6 source.

Validation: 29 focused tests, 226 assertions, zero failures across `physical-preparation-worker-boundary`, `physical-preparation-leases` and `physical-scene-transfer`. The actual module worker preserves exact prepared meshes, render buffers, picking acceleration and ownership diagnostics in both mesh modes across all three test floor selections. Host Plan remains complete. The pool registration test separately proves that Plan drawing is absent from the worker-owned source while object Plan lines and surface annotations remain present. Existing cancellation, failure, release, family affinity and detached-buffer checks continue to pass.
