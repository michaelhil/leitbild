# Atomic BVH self-pair traversal

This candidate replaces repeated per-face ownership queries with standard BVH self-collision traversal. A node paired with itself visits its left/self, left/right and right/self combinations. A distinct node pair splits the larger surface-area node until atomic leaves are reached. Each unordered face pair is considered once. Node area chooses traversal only; there is no geometry, candidate, component or depth limit.

Parent pairs reject separation only when both floating-point query orientations reject it. Atomic leaves then use the original earlier-cover/later-query orientation, including its unchanged numerical padding. The projected-area guard, exact pair AABB guard and robust plane predicates remain intact. Only eligible coplanar candidates are stored in sparse per-face buckets, then sorted by original source ordinal before the unchanged partitioning pass. The implementation never materialises a raw all-pairs list or groups approximate planes.

The temporary traversal adds one Float64 surface-area value per BVH node and the sparse eligible buckets. These live only during ownership preparation; retained source, geometry, picking and GPU buffers do not acquire another field. This trades temporary preparation memory for fewer repeated traversals, rather than hiding cost in permanent caches.

The focused pair oracle compares the resulting pairs against the existing atomic hierarchy's original leaf queries on equal, touching, random, translated, near-zero and extreme finite bounds.
