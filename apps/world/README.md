# World Module

Owns Scenarios, Simulation Runs, the map, Pack runtimes, procedure execution and historical observations.

Read the [wiki](https://leitbild.app/wiki) and [scenario guide](https://leitbild.app/wiki?path=guides%2Fscenarios.md). Exact Pack schemas and operations are published by their code; the wiki explains meaning and limitations rather than duplicating those inventories.

Run checks and tests through this Module's `package.json` scripts. Preserve the invariants in `AGENTS.md`.
