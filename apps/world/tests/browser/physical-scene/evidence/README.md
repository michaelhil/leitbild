# Executed proof and corrections

`desktop.json` is the successful final isolated GPU run on Apple M2, Chrome 155/ANGLE Metal, AA enabled, 1440×913 DPR 1. Its source hashes pin the actual tested production renderer/compiler/Deck files. All twenty mount cycles, twenty full style replacements and one forced context restoration pass. Shared GL state, color/depth/stencil, real owner-icon Deck picking, visible source-triangle picking, status pixels without geometry upload, immediate stale-floor pick invalidation and a deliberate-clear negative control pass. The 638×720 plan and 3D source-volume corner bounds are recorded. These PNGs are test views; the red status is a controlled shader input and the corner rectangles are diagnostic sentinels.

The initial readiness failure is retained in `initial-ready-failure.json`. A complete style replacement could leave an admitted scene ready while the style was not yet ready to register its GPU layer. The controller now reconciles at idle readiness; unchanged idle reconciliation requests no new frame. The focused regression checks this transition and absence of a self-generated repaint loop.

`initial-recovery-not-quiescent.json` records seventeen scene frames during a 350 ms observation immediately after context restoration. The final stationary check begins after 500 ms recovery quiescence and records zero frames despite five repeated identical style-map updates. This does not claim zero work during context recovery or qualify recovery latency. Equal style maps are now ignored by the production controller, protecting paused views from the UI's freshness-clock updates.

Visual review also found that an upper deck's thickness overlapped the lower floor's vertical band. Slabs now follow their authored floor, while genuinely spanning objects use cut fragments. The 2D representation flattens those fragments into XY with small presentation depth bands, preserving vector lines, door swings and matching picks without retaining tall-column perspective. Source geometry is unchanged. A pre-frame level change invalidates old pick/anchor data, then rendering publishes the new view.

Two harness errors were corrected before qualification: operational Deck visibility uses its actual `objects` family rather than internal scheduler family names, and diagnostic sentinel layers must be recreated after forced context restoration. The driver now refuses a CDP exception or any result without a boolean completed gate. Custom layers are absent from MapLibre's serialized `getStyle().layers`; actual composition checks and ordering use its public `getLayersOrder()` API.

This proof does not exercise production PMTiles, constrained hardware, WAN, the full faceplate/input stack or real Run acquisition. Those remain separate combined application checks.
