# The Leitbild Assistant uses an ordinary Agent Room

The Leitbild Assistant is a reusable Agents-owned Room with one ordinary Agent. The same Room Definition serves Workspace, single-Resource, and collection scopes; scope is selected when the Room is created and may be replaced by a human later. Focused Subjects carry transient browser attention but never expand the Room Scope. The Agent explicitly selects its assistance Skill, uses product-source tools and the generic Workspace broker, and resolves free-form places separately from authored geodata collections. Scenario candidates remain ordinary Scenario Definitions and become immutable revisions only when explicitly saved. We rejected an Assistant Pack, a privileged Host AI service, name-scoped Skills, separate Workspace/Simulation Assistant types, and separate task or draft resources because each would duplicate lifecycle, access, persistence, or orchestration mechanisms without an independent domain need.
