# The Leitbild Assistant uses an ordinary Agent Room

The workspace-wide Leitbild Assistant is one reusable Agents-owned Room with one ordinary capability-limited Agent, opened from the Host and given the Client's current Focused Subjects. A subject is either a live Resource or an exact immutable Definition Revision; it is transient attention, not authority or Room history. The Agent explicitly selects its assistance Skill, uses bounded product-source tools and the existing Workspace Capability Broker, and resolves free-form places separately from authored geodata collections. Scenario candidates remain ordinary Scenario Definitions and become immutable revisions only when explicitly saved. We rejected an Assistant Pack, a privileged Host AI service, name-scoped Skills, a generic Assistant workflow layer, and separate task or draft resources because each would duplicate lifecycle, permissions, persistence, or orchestration mechanisms without an independent domain need.
