# Situation Monitor observes without driving physics

Situation Monitor is a World Pack selected in an ordinary Scenario, including monitor-only Scenarios. Its Run owns source configuration and lifetime, while Workspace-shared collectors use observation time and bounded evidence storage; external reports neither become simulated assets nor drive other Packs without an explicit validated operation. This reuses existing discovery and Agent tooling without introducing a parallel Monitor/Subscription resource hierarchy or conflating live feeds with the simulation clock.
