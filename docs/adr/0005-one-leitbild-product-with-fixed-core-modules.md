# Use one Leitbild product with fixed core Modules

Leitbild is one product on one public origin, and every Workspace provisions a fixed core Module set. Experience composition and user-controlled Module installation are removed because they duplicate product structure without useful variability; Module boundaries, lazy runtime activity, independent state ownership, and explicit provisioning failures remain so the unified product does not become a domain monolith. ADR 0006 later corrects the initial three-Module set to World and Agents.
