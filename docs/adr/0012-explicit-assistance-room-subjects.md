# Assistance Rooms are explicit and select Resources

Opening or copying a World Run creates only that Run. The Host opens an Agents Room only when a person explicitly opens the Run Assistant. The Agents Module discovers exactly one ordinary Room Definition whose `assistance` metadata matches either the Workspace or the selected Resource type; no Definition id, Agent id, Pack id, or model name is embedded in the Host.

A Run Assistant Room stores a generic Subject Selection, not a World-specific binding. It may select one Resource or members of a Resource collection using either `all except` or `selected only`. World publishes each Run Family as a derived `world.run-family` Resource with `contains` links, while member Runs publish `member-of`. The default selection is all family members, so later what-if copies are automatically in scope without events, synchronization, or duplicated membership state. Additional Rooms choose their initial Runs explicitly and may opt into future copies. Subject Selection is conversation scope; Tool Grants remain separate authority and are checked against the live catalog at invocation time.

Run Family deliberately is not a persisted entity, service, aggregate, transaction boundary, or generic collection framework. Its stable id already exists in Run copy provenance; World derives the family descriptor from known Runs on each catalog read. Deleting the original therefore does not destroy a family while copies remain. When its last Run is deleted the derived Resource disappears, but an existing Room and conversation remain, with no live subjects until changed or deleted. References are always compared by Workspace, Module, type, and id because a family and its original may legitimately share an id.

The Host shows World alone by default. The Run Assistant button creates or reuses the oldest matching Assistance Room, shows only Rooms whose Subject Selection covers the current Run, and embeds Agents in focused mode with its rail collapsed. Hiding the pane does not delete the Room. If the visible Run was explicitly excluded, opening Assistance is an equally explicit request to add that Run back while preserving the selection mode and every other exclusion. The Room selector and scope editor live in the Host because they compose World Resources with an Agents Room; Agents remains the sole owner of Room persistence, membership, Agents, messages, and grants. Deleting a Definition-created Room also deletes its Room-owned AI profiles and Room-scoped triggers.

This rejects automatic companion Rooms, per-Run Room duplication, a persisted family registry, copy-created events, Host-owned Agent state, Agent profiles containing Run ids, and a universal relationship engine. Those alternatives add synchronization and lifecycle failure modes without an independent domain need.
