# Agents assistance lifecycle and reliability

World Run creation and copying have no Agents side effects. Assistance is an explicit Agents-owned lifecycle reached through discoverable Workspace operations. One ordinary revisioned Room Definition supports every scope. Creation is serialized per scope, persisted before success, and reuses the oldest matching Room. A failure while creating membership rolls back the Room and its spawned AI. Definition-created AI profiles carry only their owning Room id, never World Resource ids, and are removed with that Room.

Rooms persist one generic Scope. Workspace scope is broad; Resource scope contains one live Resource plus its source Definition; collection scope is either dynamic `all except` or fixed `selected only`. The broker resolves collection membership from both `contains` and `member-of` links in the live catalog, compares complete Resource identity, and checks scope plus operation applicability on every call. Optimistic scope revisions prevent concurrent browser edits from silently overwriting one another. Agents cannot expand their own Room Scope.

The embedded Agents UI receives a focused Room URL, filters its authoritative snapshot to that Room and its members, and starts with the left rail collapsed. The Host rejects a World/Room URL combination when the Room does not contain the Run. Hiding and reopening the Agent pane preserves server-side conversation state. Room creation, Run copying, dynamic family resolution, subset exclusion, concurrent assistance opening, runtime eviction/restore, failed membership rollback, Room-owned Agent cleanup, and real Host → Agents → World invocation are regression-tested.

World Run restrictions are initialized from the Scenario and then owned by the Run. A human can replace the exact blocked operation/object set with optimistic concurrency. The event journal and snapshot preserve changes; deleted objects are removed from the restriction set. World enforces restrictions for AI callers at the operation boundary, and AI callers cannot modify the restriction set.
